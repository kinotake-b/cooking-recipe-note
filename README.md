# cooking-recipe-note

AIが考えたレシピを貼り付けて貯めておく，個人用の料理レシピノート．1つのHTMLファイル(`index.html`)だけでできている．

- レシピのデータは，開いた端末のブラウザの中にだけ保存される(このリポジトリには載らない)
- 機能:AIの回答を料理名・材料・作り方・保存方法に自動で分ける／写真／調理モード／世界の料理マップ／食材マップ／家にある食材／レベルとXP／AIへの質問文づくり(音声入力つき)
- バックアップは画面下の「書き出す」から

## データの出典
- 「東京の平均価格」(値段帳にない食材の材料費の目安):東京都総務局統計部「東京の物価」東京都区部消費者物価指数(月報) 第7表 主要品目の東京都区部小売価格(2025年9月〜2026年9月の直近12か月の平均).[クリエイティブ・コモンズ 表示 4.0(CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/deed.ja).統計にない食材には近い品目の値段を使い,画面にそう表示している.加工:月ごとの価格を平均し,食材辞書の名前に対応づけた.
- 食材1個あたりの重さの目安は,標準的な大きさの目安で,公的な基準ではない.
- 食材辞書(364件)の別名・売り方・重さは,一般的な呼び方や標準的な大きさの目安をもとにした.平均価格が付くのは,統計に品目がある約180件と,近い品目の値段を使うもの(画面に表示).ルウ・合わせ調味料・レトルトなどのキット類は,統計の「1箱」「100g」などの単位のまま.
